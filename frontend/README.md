# Campus Lost & Found Portal - Frontend Application

A responsive React + Vite single page application with integrated student portal and full-featured Admin Dashboard.

## 🚀 Quick Run Guide

### 1. Install dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The application runs at:
- **Student Portal**: `http://localhost:5173/` (or `http://localhost:5174/`)
- **Admin Portal**: `http://localhost:5173/admin` (or `http://localhost:5174/admin`)

---

## 🔑 Default Admin Credentials

- **URL**: `/admin`
- **Email**: `admin@campus.edu` *(or `admin@campusfind.com`)*
- **Password**: `admin123`

---
